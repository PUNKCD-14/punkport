# PunkPort

PunkPort is my personal portfolio website. It introduces who I am, shows my skills and my Google AI Professional Certificate, and gives visitors a way to contact me. I built it for the Web Development module (Information Technology: System Development, Year 2) at Gauteng City College.

**Student:** Casey Ryan Du Plessis
**Lecturer:** Mr Owami

## Live Website

https://punkcd-14.github.io/punkport/

**Repository:** https://github.com/PUNKCD-14/punkport

## Technologies Used

- **HTML5** – page structure and content
- **CSS3** – styling, Flexbox, Grid, responsive layout and hover effects
- **JavaScript** – mobile navigation menu toggle
- **Boxicons** – icons
- **Google Fonts (Poppins)** – typography
- **Git and GitHub Pages** – version control and hosting

## Features

- Responsive layout for desktop, tablet and mobile
- Mobile menu that opens and closes with a toggle button (JavaScript)
- Sections: Home, About, Skills, Achievements and Contact
- Google AI Professional Certificate with all 7 courses and a Coursera verification link
- Custom orange, purple and black design with a gradient logo and glowing profile picture
- Smooth scrolling and hover effects on buttons, icons and cards
- Contact form with HTML5 validation (required fields and email format check)
- Links to my GitHub and LinkedIn profiles

## Run Locally

1. Clone the repository:
```
   git clone https://github.com/PUNKCD-14/punkport.git
```
2. Open the `punkport` folder.
3. Double-click `index.html` to open it in your browser.
